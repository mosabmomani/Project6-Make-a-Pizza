Pizza Order Desktop Application 🍕

A fully interactive C# Windows Forms application developed as part of desktop application programming practice. This project allows users to customize their pizza orders with real-time price calculation and order summaries.

Features

Pizza Size Selection: Choose between Small ($10), Medium ($15), and Large ($20) with dynamic pricing updates.

Crust Type Options: Select between Thin Crust ($5) and Thick Crust ($10).

Customizable Toppings: Add multiple toppings such as Extra Cheese, Mushrooms, Tomatoes, Onion, Olives, and Green Peppers (each with individual pricing).

Dining Options: Choose between "Eat In" or "Take Out".

Quantity Control: Use the numeric selector to order up to 25 pizzas at once, with the total price updating automatically.

Order Confirmation & Reset: Confirm your order with a prompt that locks the form controls, or use the reset button to start a new order.

Technologies Used

Language: C#

Framework: .NET Framework 4.7.2

UI Toolkit: Windows Forms (WinForms)

Getting Started

Clone the repository:

git clone https://github.com/mosabmomani/Pizza-Order-WinForms.git


Open the solution file (Project (8) Make a Pizza.sln) in Visual Studio.

Build and run the application (F5).
